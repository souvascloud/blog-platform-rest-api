# Blog Platform REST API

Production style REST API for a blog platform built with **Spring Boot**.  
This project showcases best practices in REST API design, validation, error handling, security, and clean architecture.

> The project is being built step by step. Current focus: common foundation, API consistency, and configuration.

---

##  Features

- Clean RESTful API design
- Consistent API response envelope
-  Global exception handling
-  Custom error codes & API errors
-  Request validation (Jakarta Bean Validation)
-  Custom validators (slug, strong password)
- Slug utility for SEO-friendly URLs
- Environment-based configuration using YAML & profiles
- JWT authentication & authorization
- User, Post, Comment, Like, Tag modules
- Admin APIs for moderation
- Swagger / OpenAPI documentation
- Unit tests

---

##  Tech Stack

- Java 17
- Spring Boot 3.x
- Spring Web
- Spring Data JPA
- Spring Security
- PostgreSQL
- Maven
- Lombok
- Springdoc OpenAPI (Swagger)
